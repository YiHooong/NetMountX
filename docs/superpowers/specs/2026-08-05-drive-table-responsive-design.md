# 驱动器状态表自适应显示设计

## 目标

改善主界面驱动器表格的可读性，并保证从开机自启动后首次打开窗口时，尺寸与正常启动一致且不会小于应用设定的最小尺寸。

## 表格列行为

- “名称”和“网络路径”列以其内容的合理宽度为基础，并在窗口变宽时共享额外空间。
- 两列设定最小宽度；当窗口宽度不足以容纳所有可见列时，表格保留横向滚动条，用户可横向查看完整名称和路径，不以压缩列宽换取无滚动。
- 其余控制列维持稳定宽度，避免挂载策略、状态及自动挂载开关在调整窗口时跳动。
- “状态”列的表头和每行状态文本均为水平、垂直居中；状态颜色和悬浮说明保持现有行为。

## 窗口行为

- 主窗口显式设置最小尺寸，防止布局计算或平台默认值将窗口缩至不可用范围。
- 启动时保存默认显示尺寸。
- 使用 `--minimized` 启动时，在托盘首次显示窗口前恢复该默认尺寸并确保不小于最小尺寸；普通启动路径保持现有默认窗口尺寸。

## 验收条件

1. 长名称和长网络路径在宽窗口下能获得更多显示空间；窄窗口下可通过横向滚动条查看完整文本。
2. 调整主窗口大小时，名称和网络路径列会随可用空间调整，不会固定在原宽度。
3. 状态列每行文字与“状态”表头均居中对齐。
4. 从开机自启动进入托盘后，首次点击“显示主窗口”时，窗口尺寸不小于设定的最小尺寸，并显示为默认大小。
5. 现有双击编辑、状态详情、自动挂载开关和列显示/隐藏设置不受影响。

## 验证策略

- 为窗口尺寸恢复和列宽策略提取可独立检查的辅助逻辑，并先用回归测试覆盖最小尺寸与横向滚动的决策。
- 运行现有自检，并进行桌面端手动检查：普通启动、`--minimized` 后从托盘首次显示、宽/窄窗口下的列布局与状态居中效果。
